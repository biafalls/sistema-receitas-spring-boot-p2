# Sistema de Receitas

## Sobre

Projeto acadêmico desenvolvido em dupla para a disciplina de **Linguagem de Programação III**, cursada no **quinto semestre da graduação**.

A aplicação consiste em um sistema web para gerenciamento de receitas, desenvolvida com **Java**, **Spring Boot** e **Thymeleaf**, aplicando conceitos de arquitetura MVC, Programação Orientada a Objetos e persistência de dados com **MySQL**.

## Funcionalidades

- Cadastro de receitas
- Listagem de receitas
- Edição de receitas
- Exclusão de receitas
- Exibição da categoria das receitas

## Tecnologias utilizadas

- Java
- Spring Boot
- Thymeleaf
- HTML
- CSS
- MySQL
- Maven
